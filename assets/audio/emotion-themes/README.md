# Emotion Theme Music

감정별 영상 배경음악 파일 보관 안내입니다.

현재 앱은 `constants/emotionThemeMusic.ts`에서 아래 파일을 import합니다.

- `assets/audio/happy.mp3` - 행복함 / 행복
- `assets/audio/sad.mp3` - 슬픔
- `assets/audio/anger.mp3` - 분노
- `assets/audio/excitement.mp3` - 흥분 / 신남
- `assets/audio/impressed.mp3` - 감동
- `assets/audio/scared.mp3` - 공포
- `assets/audio/ambiguous.mp3` - 알 수 없음 / 미묘

파일 위치를 바꾸면 `constants/emotionThemeMusic.ts`의 `require(...)` 경로도 같이 수정해주세요.
